# Repository instructions

## Session work log

When working on behalf of this repository's owner, record each substantive Codex work session in the private [project work log](https://github.com/emilliga/project-work-log) as part of session closeout, even if the session produced no source commit. Record the source repository as `owner/repo`, the Europe/Paris date, active minutes and their basis (measured, estimated, or unknown), tasks, ideas explored, progress, achieved objectives, and relevant links. Split work by date and repository, and count active time once.

Follow the tracker's entry template, regenerate and check its weekly report, then commit and publish the entry and report together. Keep credentials and sensitive details out of entries. If tracker access is unavailable, save the entry locally and report the blocker. Never create duplicate entries for the same work block.
